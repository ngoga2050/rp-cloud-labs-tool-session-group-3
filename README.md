RP-Cloud Labs — Tool-Session Service

1. Project Overview

RP-Cloud Labs is a proposed platform that provides students and lecturers with browser-based access to hosted learning tools without requiring local software installation.

 2. Purpose

The Tool-Session Service allows students to request access to learning tools, such as programming environments and other practical applications, while checking whether their college has available software license capacity.

3. Main Objectives

- Allow students to request tool sessions.
- Validate session requests.
- Track license capacity for each college.
- Provide reliable and consistent access to hosted learning tools.
- Support secure and maintainable software deployment.

 4. Technologies

- GitHub and GitHub Actions for source control and CI/CD.
- Docker for application containerization.
- Kubernetes for deployment and orchestration.
- Flyway for database schema migrations.
- Redis for caching active session information.
- Kafka for publishing session-related events.

 5. Development Approach

The group will use Agile development, feature branches, pull requests, automated testing, and continuous integration.
